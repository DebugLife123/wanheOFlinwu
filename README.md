# 临武万和订单管理系统

本项目用于万和热水器、喜乐乐取暖桌等商品的内部经营管理，覆盖商品、进货、库存、销售订单、客户、安装售后和经营报表。系统只供店内人员使用，不提供在线商城、在线支付或面向顾客的交易功能。

## 当前基线

- 文档版本：`v0.2`
- 编制日期：`2026-08-02`
- 项目阶段：核心需求已确认，待业务样例与页面原型确认

## 第一版原则

- 先跑通“商品建档 -> 进货入库 -> 销售出库 -> 客户安装 -> 售后追踪”的闭环。
- 库存只能由业务单据或有理由的库存调整改变，不能直接覆盖库存数字。
- 订单状态、收款状态、配送状态和安装状态分别记录，避免混成一个无法解释的状态。
- 所有关键修改保留操作人、操作时间和变更内容。
- 第一版不做在线支付、顾客商城、复杂财务核算、多门店调拨和原生 App。

## 已确认业务基线

- 只设置“管理员”和“用户”两种角色；安装与售后人员使用自己的用户账号。
- 用户可以查看处理业务所需的客户完整地址，成本、利润、账号、审计和系统配置仅管理员可见。
- 支持多个仓库/库位，并区分正常商品、样机、赠品、损坏品和厂家直发。
- 对需要追踪的商品逐台记录序列号、机身码或保修卡号。
- 迁移现有商品、客户和订单数据，规模在 1 万条以内。
- 支持销售单、安装单打印或生成 PDF，纸张样式在取得样张后定稿。
- 支持多次收款、收款方式、欠款金额、约定还款日期和还款明细。

## 当前可运行版本（v0.2）

当前项目已经从纯演示原型接入本地持久化：

- 数据库：项目根目录 `data/linwu.db`，使用 SQLite（`better-sqlite3`）。首次启动会自动创建表结构并写入一批演示数据。
- 主要数据：商品与价格、仓库库存、客户、订单、订单明细、收款流水、安装/售后任务。
- 写入方式：销售开单、客户建档、收款登记、订单状态推进、售后任务创建与完成，均通过 Next.js Server Actions 写入 SQLite。
- 刷新机制：写入后通过 `revalidatePath("/")` 重新读取数据库，刷新页面不会丢失数据。
- 金额：数据库按“分”保存，界面按人民币元展示。
- 数据文件：`data/` 已加入 `.gitignore`，不会提交到 Git；正式使用前请定期备份 `data/linwu.db`。

### 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。如果端口被占用，可使用 `npm run dev -- -p 3001` 指定其他端口。

### 当前已打通的日常流程

1. 新建销售单：客户信息、商品、数量、履约来源、是否安装、预约时间、本次收款、收款方式、业务员、品牌、收款人、送货/安装、赠品和备注。
2. 查看订单：列表仅展示订单号、客户、日期、商品、金额/尾款和状态；点击“详情”后查看完整销售订单字段（含电话、地址及业务信息），并可推进“待出库 → 配送中 → 待安装/已完成”。
3. 客户管理：搜索客户、新增客户，客户订单数量和累计消费由订单数据计算。
4. 应收欠款：查看欠款，一键收讫或登记分次收款，欠款余额由收款流水自动计算。
5. 安装售后：新建任务、电话联系、标记完成，关联订单的安装任务完成后会同步订单状态。
6. 商品库存：按仓库查看可售、预留、样机、损坏和在途数量。

当前仍属于单店自用第一版，登录、打印/PDF、导出、序列号完整台账、进货入库和多用户权限暂未实现。订单扩展字段已兼容旧版 SQLite 数据库，首次启动会自动补齐缺失列。
