# 临武万和订单管理系统交互原型说明

## 1. 原型定位

本原型用于验证临武万和门店内部订单管理系统的信息架构、核心业务流程和桌面端/移动端交互，不包含真实交易、在线支付、正式权限校验或持久化数据库。

当前界面中的客户、订单、金额、库存、序列号和经营指标均为演示数据。

## 2. 本地运行

环境要求：Node.js 20 或更高版本。

```powershell
npm install
npm run dev
```

浏览器打开终端显示的本地地址。生产构建检查使用：

```powershell
npm run typecheck
npm run build
```

所有前端依赖均安装在本项目的 `node_modules` 中，不依赖全局 npm 包。

## 3. 可演示流程

1. 工作台查看待出库、安装售后、逾期欠款和低库存提醒。
2. 销售订单按状态筛选，并触发打印或导出演示反馈。
3. 商品库存按门店仓、后仓、临时仓查看可售、样机、损坏、预留和在途数量。
4. 查看逐台设备序列号，演示仓库调拨操作。
5. 查询客户档案、历史订单和安装地址。
6. 查看安装及售后人员任务，并允许内部账号查看完整地址。
7. 查看应收欠款、约定还款日和逾期状态。
8. 使用全局搜索查询订单号、客户、商品型号或序列号。
9. 新建销售单，选择商品、数量、仓库或厂家直发、序列号和安装预约，实时计算订单合计。
10. 在移动端使用底部导航和全部功能侧滑菜单。

## 4. 响应式范围

原型已经针对 320、375、414、768 和 1440 像素宽度进行检查。移动端采用底部主导航和侧滑菜单，桌面端采用固定侧边栏；核心按钮的可见触控区域不小于 40 像素。

## 5. 业务边界

- 角色暂定为管理员和用户两类，正式开发时通过权限矩阵控制菜单、字段和操作。
- 库存支持多仓库、样机、赠品、退货、损坏和厂家直发；正式系统需要以库存流水为审计依据。
- 商品支持序列号、机身码和保修卡号逐台追踪；厂家直发可在安装前补录。
- 收款支持分次登记、收款方式、欠款余额、约定还款日和催收备注。
- 正式系统需要补充登录鉴权、数据库、备份恢复、导入迁移、打印模板、操作日志和数据权限测试。
